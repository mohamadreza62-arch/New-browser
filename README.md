# مرورگر خصوصی (Private Browser)

یک مرورگر ساده‌ی اندرویدی با قابلیت‌های زیر:

- **هیچ تاریخچه‌ای ذخیره نمی‌شود**: کش، کوکی‌ها، داده‌ی فرم‌ها، پسورد‌ها و Web Storage هرگز روی دیسک نگه‌داری نمی‌شوند.
- **بستن خودکار همه‌ی تب‌ها**: به محض اینکه برنامه مینیمایز شود (دکمه Home زده شود یا کاربر برنامه‌ی دیگری باز کند)، تمام تب‌های باز فوراً بسته و نابود می‌شوند و تمام داده‌های سشن (کوکی، کش، Storage) پاک می‌شود. وقتی دوباره برنامه باز شود، همیشه با یک تب خالی شروع می‌کنید.
- چند‌تب بودن، نوار آدرس، جستجوی گوگل برای عبارت‌های غیر URL، و دکمه‌ی back که ابتدا تاریخچه‌ی همان صفحه (در حافظه، نه دیسک) را طی می‌کند.

## روش اول (روی کامپیوتر): Android Studio

1. [Android Studio](https://developer.android.com/studio) را نصب کنید.
2. گزینه‌ی **Open** را بزنید و پوشه‌ی `PrivateBrowser` را انتخاب کنید.
3. صبر کنید تا Gradle sync تمام شود.
4. با کلیک روی **Run ▶** برنامه را روی گوشی یا شبیه‌ساز نصب کنید، یا از منوی `Build → Build APK(s)` فایل APK بگیرید.

## روش دوم (فقط با گوشی، بدون نیاز به کامپیوتر): GitHub Actions

این پروژه از قبل یک فایل `.github/workflows/build.yml` دارد که ساخت APK را به‌طور خودکار در سرورهای GitHub انجام می‌دهد.

1. در مرورگر گوشی وارد **github.com** شوید و یک حساب رایگان بسازید (اگر ندارید).
2. یک ریپازیتوری جدید و **خصوصی یا عمومی** بسازید، مثلاً با نام `PrivateBrowser`.
3. تمام محتوای پوشه‌ی `PrivateBrowser` (همان چیزی که داخل این zip است) را در ریشه‌ی ریپازیتوری آپلود کنید:
   - در صفحه‌ی ریپازیتوری گزینه‌ی **Add file → Upload files** را بزنید.
   - zip را ابتدا با یک اپ فایل‌منیجر (مثل Files by Google یا ZArchiver) اکسترکت کنید، سپس تمام پوشه‌ها و فایل‌ها (شامل پوشه‌ی مخفی `.github`) را انتخاب و آپلود کنید. اگر گوشی اجازه‌ی انتخاب پوشه‌ی مخفی را نداد، فایل `.github/workflows/build.yml` را جداگانه از طریق «Add file → Create new file» بسازید و مسیر و محتوای همان فایل را کپی/پیست کنید.
4. بعد از آپلود (که خودش یک commit به شاخه‌ی `main` است)، به تب **Actions** در بالای صفحه‌ی ریپازیتوری بروید.
5. یک ورک‌فلو به نام **Build APK** به‌صورت خودکار شروع به اجرا می‌کند (چند دقیقه طول می‌کشد).
6. وقتی تیک سبز ✅ ظاهر شد، روی همان اجرا کلیک کنید، پایین صفحه بخش **Artifacts** را باز کنید و فایل `PrivateBrowser-debug-apk` را دانلود کنید (یک zip حاوی `app-debug.apk` است).
7. فایل apk را اکسترکت و روی گوشی باز/نصب کنید. اگر گوشی هشدار «منبع ناشناس» داد، در تنظیمات گوشی اجازه‌ی نصب از آن اپ (مثلاً مرورگر یا فایل‌منیجر) را فعال کنید.

هر بار که کد را در گیت‌هاب تغییر دهید (ویرایش فایل، آپلود مجدد)، این ورک‌فلو خودش دوباره اجرا و APK جدید می‌سازد؛ دیگر نیازی به کامپیوتر یا Android Studio نیست.

## ساختار پروژه

```
PrivateBrowser/
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/example/privatebrowser/MainActivity.kt   ← منطق اصلی مرورگر
│       └── res/
│           ├── layout/activity_main.xml
│           └── values/ (strings.xml, themes.xml)
├── build.gradle
└── settings.gradle
```

## نکات فنی حریم خصوصی (در MainActivity.kt)

- `cacheMode = WebSettings.LOAD_NO_CACHE` و `databaseEnabled = false`
- `saveFormData = false` و پاک‌سازی `WebViewDatabase` (فرم/پسورد ذخیره نمی‌شود)
- کوکی‌ها فقط برای طول سشن نگه داشته می‌شوند و با `CookieManager.removeAllCookies` پاک می‌شوند
- `WebStorage.getInstance().deleteAllData()` برای پاک کردن localStorage/IndexedDB
- تابع `wipeEverything()` در `onStop()` (زمان مینیمایز شدن) و `onDestroy()` صدا زده می‌شود و همه‌ی WebViewها را `destroy()` می‌کند
